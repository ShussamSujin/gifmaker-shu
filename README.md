# GIFMaker.SHU

GIFMaker.SHU captures a user-selected screen area directly into GIF frames, opens a short edit step for trimming, captions, and stickers, and saves a GIF without creating an intermediate MP4 file.

## Contents

- `docs/`: bilingual Korean/English website — deployed to https://gifmaker.shu.is via GitHub Pages (main branch, /docs)
- `extension/`: bilingual Manifest V3 Chrome extension
- `STORE_LISTING_KO.md`: Korean Chrome Web Store copy
- `STORE_LISTING_EN.md`: English Chrome Web Store copy

## Privacy boundary

Screen frames, imported images, edit layers, and generated GIFs are processed locally in the browser. The app does not upload them to an operator server.

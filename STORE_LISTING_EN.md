# GIFMaker.SHU - Capture any area to GIF

## Short description
Capture any screen area for up to 60 seconds, add captions and stickers, and save directly as a GIF.

## Detailed description
GIFMaker.SHU is a lightweight Chrome extension that turns a selected screen area directly into a GIF with no intermediate MP4 file.

- Choose a tab, window, or full screen
- Drag over the preview to select an exact area
- Record for up to 60 seconds
- Choose 5–12fps, 480–960px, and 64–256 colors
- Trim the start and end immediately after capture
- Add simple scene-based captions and stickers
- Save only the finished GIF
- Local browser processing with no screen or file upload to an operator server

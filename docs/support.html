GIF 만들기

  1. 화면 선택하기를 누르고 Chrome 창에서 탭, 창 또는 화면을 선택합니다.
  2. 미리보기 위에서 필요한 영역을 드래그합니다.
  3. 길이·속도·크기·색상을 고르고 촬영 시작을 누릅니다.
  4. 촬영 후 편집 화면에서 시작·끝 구간, 자막과 스티커를 조정합니다.
  5. GIF 만들기를 누르고 완성 파일을 저장합니다.

1분 GIF가 너무 클 때

GIF는 동영상보다 파일이 커질 수 있습니다. 60초 촬영은 480–640px, 5–8fps, 64–128색을 권장합니다. 짧은 GIF는 800–960px와 256색을 사용할 수 있습니다.

화면이 선택되지 않을 때

브라우저의 화면 공유 창에서 대상을 선택해야 합니다. 학교·회사 관리 기기에서는 관리자가 화면 캡처를 제한했을 수 있습니다.

Create a GIF

  1. Choose a tab, window, or screen in Chrome’s sharing dialog.
  2. Drag on the preview to select the area you need.
  3. Choose length, frame rate, size, and color quality, then start recording.
  4. Trim the result and add scene-based captions or stickers.
  5. Build and save the finished GIF.

If a 60-second GIF is too large

GIF files can be much larger than video. For 60 seconds, use 480–640px, 5–8fps, and 64–128 colors. For shorter GIFs, try 800–960px and 256 colors.

If screen sharing does not open

You must choose a source in Chrome’s sharing dialog. A school or company administrator may disable screen capture on managed devices.

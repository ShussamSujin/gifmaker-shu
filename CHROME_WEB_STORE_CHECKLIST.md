## Reviewer note

The extension opens a local capture page only after the user clicks the toolbar icon or keyboard shortcut. Chrome's native screen-sharing picker asks the user to select a tab, window, or screen. Captured frames are held in the current browser session, edited locally, encoded by a bundled GIF library, and downloaded as a GIF. No intermediate MP4 file is created and no capture content is uploaded.
